# Betty 🎯

**Tinder for Predictions** - Swipe your way through prediction markets.

## Features

- 👆 **Swipe Interface** - Right for YES, Left for NO, Down to SKIP
- 💰 **USDC Deposits** - Fund your wallet on Base, Arbitrum, or Polygon
- 🎲 **Micro-betting** - Configurable bet amounts ($0.05 - $1.00 per swipe)
- 📊 **Track Performance** - See your prediction history and accuracy

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Demo Mode

Click "Demo: Simulate deposit" on the Wallet page to add test funds without real crypto.

## Tech Stack

- React + Vite
- Tailwind CSS
- React Router

## User Flow

1. **Welcome** → Get Started
2. **Wallet** → Deposit USDC, set bet amount
3. **Predict** → Swipe through predictions
4. **Profile** → View your stats
